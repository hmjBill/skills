# AI-Wiki 写作辅助

基于库内已有笔记素材，辅助用户完成写作任务。

## 触发场景

- "帮我写一篇关于 X 的文章"
- "基于我的笔记写个初稿"
- "把这个笔记扩写一下"
- "改写这段内容的风格"

## 步骤

### 1. 理解写作意图

收集以下信息：
- 主题：写什么
- 用途：博客、内部文档、笔记总结、项目文档、社交媒体
- 风格：正式/轻松/学术/技术
- 长度：大致篇幅
- 素材来源：用户指定的笔记或由 skill 搜索

### 2. 搜索库内素材

根据主题在笔记库中搜索相关内容：
- 通过 obsidian-cli 搜索关键词
- 读取相关笔记获取素材
- 整理可用素材清单，标注来源笔记路径

### 3. 素材整理

将收集到的素材按逻辑排序：
- 列出核心论点/信息点
- 标注每个信息点的来源笔记（wikilink）
- 识别素材缺口（缺少的信息）

### 4. 生成初稿

基于素材生成写作初稿：
- 按用途选择合适的结构
- 引用库内知识，标注 [[wikilink]] 来源
- 缺口部分用通用知识补充，明确标注 `[外部知识]`

### 5. 用户审阅

将初稿展示给用户，提供以下选项：
- 满意 → 继续落库
- 需要调整 → 按反馈修改
- 换个角度 → 重新组织素材生成

### 6. 落库或输出

| 用途 | 处理方式 |
|------|---------|
| 笔记库内文章 | 基于 `资源模板.md` 创建到 `05_资源/`，更新 README |
| 项目文档 | 基于 `项目模板.md` 创建到 `03_项目/`，更新 README |
| 仅输出不落库 | 直接输出文本，不创建文件 |
| 领域总结 | 基于 `领域模板.md` 创建到 `04_领域/`，更新 README |

### 7. 更新导航（落库时）

更新目标目录 README 的 `## 导航入口`。

## 支持的写作模式

### 初稿生成

从零开始，基于库内素材生成完整初稿。适合开始新文章。

### 扩写

用户提供一段文字 + 目标方向，搜索库内相关素材进行扩写。保留原文结构，在关键节点补充内容。

### 改写

用户提供一段文字，指定目标风格，在不改变核心信息的前提下改写。

### 综合

用户提供多个笔记的 wikilink，将它们综合成一篇连贯文章。

## 规则

- 优先使用库内素材，不凭空编造
- 库内素材标注 [[wikilink]]，外部知识标注 `[外部知识]`
- 落库时使用 `00_系统/模板/` 中的模板
- frontmatter 修改使用 `patchField`/`patchFields`
- 仅使用合法枚举值
- 不自动修改被引用的源笔记
- 如果用户只想输出不落库，不强制创建文件

## 枚举值参考

所有 frontmatter 字段的合法值定义在 `.obsidian/types.json` 的枚举注册表中。
