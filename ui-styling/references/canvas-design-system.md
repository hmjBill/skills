# Canvas 设计系统

视觉设计哲学、系统化构图与精妙的视觉传达。

## 设计哲学方法

Canvas 设计通过两阶段流程运作：

### 阶段 1：设计哲学创建

创建视觉哲学——通过形态、空间、色彩与构图表达的美学运动。不是布局或模板，而是纯粹的视觉哲学。

**创建内容：** 强调以下要点的设计宣言：
- 视觉表达优于文字
- 空间传达
- 艺术化诠释
- 以最少的文字作为视觉点缀

**哲学结构（4-6 段）：**
- 空间与形态原则
- 色彩与材质方法
- 尺度与节奏指引
- 构图与平衡规则
- 视觉层次系统

### 阶段 2：视觉表达

通过 Canvas 作品表达哲学：
- 90% 视觉设计
- 10% 必要文字
- 博物馆级执行
- 系统化图案
- 精妙构图

## 核心原则

### 1. 视觉传达优先

信息存在于设计中，而非段落里。通过以下方式表达想法：
- 色彩区域与色块
- 几何精度
- 空间关系
- 视觉重量与张力
- 形态与结构

### 2. 文字最小化整合

文字作为罕见而有力的姿态：
- 绝不使用段落
- 只保留必要词汇
- 融入视觉架构
- 小标签，大冲击
- 排版作为视觉元素

### 3. 专业工艺

作品必须看起来：
- 精雕细琢
- 倾注心血
- 无数小时打磨的成果
- 出自领域顶尖
- 大师级执行

### 4. 系统化图案

使用科学化的视觉语言：
- 重复图案
- 完美形状
- 密集的痕迹累积
- 分层元素
- 耐心的重复回报持续观看

## 设计运动示例

### 具象诗
**哲学：** 通过纪念性形态与大胆几何进行传达。

**表达：**
- 巨大的色块
- 雕塑感排版（大字、小标签）
- 粗野主义式的空间分割
- 波兰海报的张力遇上勒·柯布西耶
- 通过视觉重量与空间张力表达想法
- 文字作为罕见而有力的姿态

### 色彩语言
**哲学：** 色彩作为首要信息系统。

**表达：**
- 几何精度
- 色彩区域创造意义
- 排版极简——小号无衬线标签
- 约瑟夫·阿尔伯斯的色彩互动遇上数据可视化
- 信息以空间和色彩方式编码
- 文字只为色彩所展示的内容提供锚点

### 模拟冥想
**哲学：** 通过质感与留白进行安静的视觉沉思。

**表达：**
- 纸张颗粒、墨迹晕染
- 广袤的负空间
- 摄影与插画主导
- 排版低声细语（小、克制）
- 日式写真集美学
- 图像在页面间呼吸
- 文字少量出现——仅短句

### 有机系统
**哲学：** 自然聚类与模块化生长模式。

**表达：**
- 圆润形态
- 有机排布
- 色彩取自自然，经由建筑呈现
- 通过可视化图表传达信息
- 空间关系与图标语言
- 文字仅用于漂浮在空间中的关键标签
- 构图通过空间编排讲述故事

### 几何静默
**哲学：** 纯粹的秩序与克制。

**表达：**
- 基于网格的精度
- 大胆的摄影或冷峻的图形
- 戏剧性的负空间
- 排版精确但极简
- 小而必要的文字，大而安静的区域
- 瑞士形式主义遇上粗野主义的材料诚实
- 结构在传达，而非文字
- 每一次对齐都来自无数次打磨

## 实施指南

### 微妙的参考融入

嵌入概念 DNA 而不张扬：
- 小众参考编织于无形
- 懂的人凭直觉感知
- 其他人体验到的是大师级的抽象构图
- 如同爵士音乐家引用另一首歌
- 精妙，绝不直白
- 参考悄然加深层次

### 色彩方法

**刻意的调色板：**
- 有限的颜色（2-5 种）
- 统一的系统
- 有目的的关系
- 使用 oklch 色彩空间以保证精度
- 每一种色度都承载意义

**示例调色板：**
```
--color-primary: oklch(0.55 0.22 264)
--color-accent: oklch(0.75 0.18 45)
--color-neutral: oklch(0.90 0.02 264)
--color-dark: oklch(0.25 0.15 264)
```

### 排版系统

**偏好细字体：**
- 轻字重（200-300）
- 干净的无衬线
- 几何精度
- 标签用小尺寸
- 冲击时刻用大尺寸

**字体整合：**
- 搜索 `./canvas-fonts` 目录
- 下载所需字体
- 将排版带上画布
- 是艺术的一部分，而非数字排版

### 构图规则

**系统化方法：**
- 重复图案建立节奏
- 完美的几何形状
- 冷峻的排版
- 参考标记暗示想象的学科
- 密集的累积构建意义
- 分层图案回报注意力

**间距纪律：**
- 没有内容掉出页面
- 没有内容重叠
- 每个元素都在画布边界内
- 适当的边距不可妥协
- 呼吸空间与清晰分离
- 专业执行是必须的

### 画布边界

**技术规格：**
- 默认单页（要求时可多页）
- PDF 或 PNG 输出
- 高分辨率
- 干净的边距
- 受控的构图
- 无瑕的格式

## 多页面设计系统

创建多个页面时：

### 方法
- 将第一页视为单页的咖啡桌画册
- 沿同一哲学创建更多页面
- 明显不同但保持统一
- 页面有品味地讲述故事
- 完全的创作自由

### 一致性元素
- 共享的调色板
- 一致的排版系统
- 相关的构图方法
- 视觉语言连续性
- 贯穿始终的哲学线索

### 变化策略
- 每页独特的转折
- 不同的焦点
- 多样的空间安排
- 互补的图案
- 渐进的视觉叙事

- [ ] 边距与间距完美无瑕
- [ ] 构图与艺术统一
- [ ] 看起来精雕细琢
- [ ] 大师级执行显而易见
- [ ] 精妙，绝不业余
- [ ] 可以陈列在博物馆
- [ ] 展现出无可置疑的专业水准
- [ ] 格式无瑕
- [ ] 每个细节都完美

## 质量标准

### 应避免
- 卡通化美学
- 业余执行
- 文字堆砌的构图
- 随机摆放
- 重叠元素
- 不一致的间距
- 明显的 AI 生成痕迹
- 缺乏打磨

### 应达到
- 博物馆品质
- 杂志级水准
- 艺术品地位
- 无数小时的观感
- 顶尖工艺
- 哲学一致性
- 视觉精妙
- 系统化精度

## 精炼流程

### 第一遍
基于哲学与原则进行创作。

### 第二遍（关键）
- 不要添加更多图形
- 精炼已有内容
- 做到极其清晰利落
- 尊重极简主义哲学
- 增强与艺术的统一性
- 让现有元素更具艺术性
- 打磨而非扩张

### 最终验证
用户已经说过：“这还不够完美。必须一尘不染，是工艺的杰作，仿佛即将在博物馆展出。”

交付前应用这一标准。
