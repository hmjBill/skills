# 品牌一致性检查清单

## 视觉一致性

### Logo
- [ ] 使用了正确的 Logo 版本
- [ ] 保持适当的安全留白
- [ ] 仅使用已批准的颜色
- [ ] 所有尺寸下清晰可辨
- [ ] 无未经授权的修改

### 颜色
- [ ] 仅使用品牌调色板颜色
- [ ] 颜色应用一致
- [ ] 对比度符合无障碍要求
- [ ] 保持颜色比例

### 排版
- [ ] 使用品牌字体
- [ ] 字重/样式正确
- [ ] 层级合理
- [ ] 格式一致

### 图像
- [ ] 符合品牌风格
- [ ] 编辑/滤镜一致
- [ ] 主题合适
- [ ] 符合质量标准

## 声音一致性

### 语气
- [ ] 符合品牌个性
- [ ] 适合语境
- [ ] 各渠道一致
- [ ] 无相互矛盾的信息

### 语言
- [ ] 使用品牌术语
- [ ] 大小写一致
- [ ] 缩写使用规范
- [ ] 术语程度适当

### 信息
- [ ] 与核心信息一致
- [ ] 价值主张清晰
- [ ] 突出差异化优势
- [ ] CTA 一致

## 渠道审计

### 网站
- [ ] 首页
- [ ] 产品页
- [ ] 博客/内容
- [ ] 页脚/导航

### 社交媒体
- [ ] 头像
- [ ] 封面图
- [ ] 简介/关于部分
- [ ] 帖子模板

### 邮件
- [ ] 页眉/页脚
- [ ] 模板
- [ ] 签名
- [ ] 自动消息

### 宣传物料
- [ ] 演示文稿
- [ ] 单页简介
- [ ] 名片
- [ ] 宣传材料

## 常见问题

| 问题 | 修复方法 |
|-------|-----|
| 过时的 Logo | 替换为当前版本 |
| 偏离品牌的颜色 | 更新为调色板颜色 |
| 字体错误 | 替换为品牌字体 |
| 声音不一致 | 应用风格指南 |
| 信息混杂 | 与框架对齐 |

## 审计频率

| 资产类型 | 频率 |
|------------|-----------|
| 网站 | 每月 |
| 社交资料 | 每季度 |
| 邮件模板 | 每季度 |
| 销售物料 | 每季度 |
| 完整品牌审计 | 每年 |
