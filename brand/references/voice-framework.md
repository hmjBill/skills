# 品牌声音框架

## 声音与语气

**声音（Voice）** = 品牌的个性（保持一致）
**语气（Tone）** = 声音如何随语境调整（可变）

示例：一个友好的品牌（声音）在宣布胜利时可能热情庆祝，而在客服回复中则表现同理心（语气）。

## 声音维度

### 语气谱系
```
正式 ←――――――――――――――→ 随意
[法律文档]     [社交媒体]
```

### 语言谱系
```
简单 ←――――――――――――――→ 复杂
[消费者]       [技术 B2B]
```

### 性格谱系
```
严肃 ←――――――――――――――→ 活泼
[金融]        [娱乐]
```

### 情感谱系
```
克制 ←――――――――――――――→ 外放
[企业]      [生活方式品牌]
```

## 声音开发流程

### 步骤 1：定义个性特质
选择 3-5 个描述品牌的特质：
- 自信，但不傲慢
- 友好，但不失专业
- 博学，但不居高临下
- 创新，但不花哨
- 真实，但不随意

### 步骤 2：创建声音图表

| 特质 | 描述 | 该做 | 不该做 |
|-------|-------------|-----|-------|
| [Trait] | [Meaning] | [Example] | [Example] |

### 步骤 3：语境适配

| 语境 | 语气转变 | 示例 |
|---------|------------|---------|
| 社交媒体 | 更随意 | "Hey there!" |
| 客服支持 | 更具同理心 | "We understand..." |
| 法律 | 更正式 | "In accordance with..." |
| 销售 | 更自信 | "You'll see results..." |

## 声音测试

问以下问题：
1. 这听起来像我们的品牌吗？
2. 竞争对手会这么说吗？
3. 这能引起受众共鸣吗？
4. 这与我们的价值观一致吗？
