# 资产审批检查清单

在批准前审查营销资产的完整检查清单。

## 快速审查

在详细审查之前，先确认：
- [ ] 资产符合既定用途
- [ ] 目标受众合适
- [ ] 无明显的错误或问题
- [ ] 与 campaign 目标一致

## 视觉元素

### Logo 使用
- [ ] Logo 变体与使用场景匹配
- [ ] 保持适当的安全留白
- [ ] 满足最小尺寸要求
- [ ] 仅使用已批准的颜色
- [ ] 无未经授权的修改
- [ ] 适合当前背景

### 颜色合规
- [ ] 仅使用品牌调色板颜色
- [ ] 主色/次要色比例合理（60/30/10）
- [ ] 语义色使用正确
- [ ] 未引入偏离品牌的颜色
- [ ] 所有元素保持一致

### 排版
- [ ] 全程使用品牌字体
- [ ] 字重应用正确
- [ ] 层级合理
- [ ] 字号适合媒介
- [ ] 行高充足
- [ ] 正文无孤行/寡行

### 图像
- [ ] 符合品牌摄影风格
- [ ] 主题/内容合适
- [ ] 质量符合要求
- [ ] 已获得许可/署名
- [ ] 针对预期用途优化

## 无障碍

### 视觉无障碍
- [ ] 文本对比度 >= 4.5:1（AA）
- [ ] 大号文本对比度 >= 3:1
- [ ] 交互元素有可见焦点
- [ ] 不以颜色作为唯一标识
- [ ] 所有图像有替代文本

### 内容无障碍
- [ ] 布局清晰、易于浏览
- [ ] 字号可读
- [ ] 阅读顺序合理
- [ ] 标题结构有意义
- [ ] 链接描述目的地

## 内容质量

### 文案审查
- [ ] 符合品牌声音
- [ ] 语气适合语境
- [ ] 未使用禁用词
- [ ] 价值主张清晰
- [ ] CTA 有吸引力且清晰
- [ ] 已校对无错误

### 信息
- [ ] 与核心信息一致
- [ ] 突出差异化优势
- [ ] 强调利益而非功能
- [ ] 面向目标受众
- [ ] 无相互矛盾的说法

## 技术要求

### 文件规格
- [ ] 文件格式正确
- [ ] 分辨率合适
- [ ] 文件大小已优化
- [ ] 命名规范正确
- [ ] 包含元数据

### 平台要求
| 平台 | 已验证 |
|----------|----------|
| Instagram | [ ] 尺寸正确 |
| Twitter/X | [ ] 符合要求 |
| LinkedIn | [ ] 符合专业标准 |
| Facebook | [ ] 符合指南 |
| 邮件 | [ ] 大小低于 1MB |
| 网页 | [ ] 已针对网页优化 |

## 法律与合规

### 知识产权
- [ ] 图库图片已获许可
- [ ] 音乐/音频已获授权
- [ ] 无商标侵权
- [ ] 用户内容已获授权
- [ ] 需要时已包含署名

### 法规
- [ ] 包含必需的披露信息
- [ ] 无误导性声明
- [ ] 价格准确
- [ ] 需要时链接条款
- [ ] 符合隐私要求

## 常见问题与修复

| 问题 | 修复 |
|-------|-----|
| Logo 太小 | 增大到最小尺寸 |
| 字体错误 | 替换为品牌字体 |
| 对比度不足 | 调整颜色以满足无障碍要求 |
| 偏离品牌的颜色 | 替换为调色板颜色 |
| 图像模糊 | 使用更高分辨率的源文件 |
| 缺少替代文本 | 添加描述性替代文本 |
| CTA 力度不足 | 强化行动导向文案 |

## 自动化支持

`validate-asset.cjs` 脚本可自动检查：
- 调色板合规
- 最小尺寸
- 文件格式/大小
- 命名规范
- 基本元数据

运行：`node scripts/validate-asset.cjs <asset-path>`

## 归档

批准后：
1. 在 manifest.json 中更新资产状态
2. 添加批准人与时间戳
3. 将旧版本移至归档
4. 更新 campaign 跟踪
5. 通知相关团队
