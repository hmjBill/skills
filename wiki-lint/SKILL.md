# AI-Wiki 健康检查

检查 AI-Wiki 笔记库的健康状况，验证 schema 合规性和链接完整性。只读操作，仅输出检查报告。

## 用途

本技能替代 wiki-lint。针对 AI-Wiki 特有的规则体系执行健康检查。

## 检查项

1. **断裂的 wikilink** — `[[path]]` 指向不存在的文件
2. **缺失 README 导航** — 知识目录中的文件未出现在其 `README.md` 的 `## 导航入口` 中
3. **模板合规性** — frontmatter `type` 字段是否符合枚举注册表中的预期值
4. **枚举违规** — type、状态、收件类型、媒体类型、优先级等字段使用了非标准值
5. **缺失 frontmatter 字段** — 模板类型要求的必填字段缺失（如项目缺少 状态）
6. **孤立笔记** — 没有任何入链的文件（未从任何 README 或其他笔记链接）
7. **积压收件箱** — `01_收件箱/` 中状态为"待处理"且超过 30 天的条目
8. **链接过密** — 知识笔记中包含超过 5 条非导航 wikilink（可能存在链接污染）
9. **索引条目过长** — `00_系统/全库索引.md` 中单条说明超过 150 字符（索引用于全库导航，说明应保持简短）

## 报告格式

保存到 `08_归档/lint-YYYY-MM-DD.md`（结构参考 `00_系统/模板/README模板.md`），写入后将报告链接加入 `08_归档/README.md` 的 `## 导航入口`：

```
## 概要
- 笔记总数：N
- 问题总数：M
- 按类别统计

## 详情
按文件列出问题，附建议修复方式

## 严重度标记
- Critical — 断裂链接、枚举违规
- Warning — 缺失导航、孤立笔记
- Info — 积压条目、链接密度、索引条目过长
```

## 规则

- 只读操作 — 仅写入检查报告；`00_系统/` 与 `09_受控信息/` 为受保护目录，不写入
- 枚举值以 `00_系统/Agent操作指南.md` 的「Frontmatter 枚举值注册表」为唯一真源；`.obsidian/types.json` 仅登记字段类型，可作显示一致性交叉核对
- 禁止自动修复任何内容
- 禁止修改任何笔记内容
