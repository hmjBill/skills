# AI-Wiki 需求文档生成

将对话中的想法或需求整理为结构化的项目需求文档，归档到 AI-Wiki 的 `03_项目/` 系统。

## 定位

基于 to-prd skill 适配 AI-Wiki 项目管理结构。

## 工作流

### 1. 收集上下文

从当前对话中提取：
- 需求描述
- 约束条件
- 项目目标
- 相关背景

### 2. 结构化需求文档

使用 `00_系统/模板/项目模板.md` 创建文档。

**Frontmatter 填写：**

```yaml
type: project
状态: 进行中
项目名称: <名称>
目标: <目标描述>
开始日期: <YYYY-MM-DD>
结束日期: <YYYY-MM-DD 或空>
相关领域: <领域列表>
tags:
  - <标签>
```

**正文结构：**

- `## 目标` → 项目目标和完成标准
- `## 进展` → 初始需求分解
- `## 备注` → 需求文档详细内容（见下方模板）

### 3. 路由决策

| 情况 | 目标目录 | 模板 | 状态 |
|-----|---------|------|------|
| 有明确目标和截止日期 | `03_项目/进行中/` | 项目模板.md | 进行中 |
| 仅是想法/灵感 | `01_收件箱/` | 收件箱模板.md | 收件类型: 灵感 |
| 需要讨论 | `01_收件箱/` | 收件箱模板.md | 收件类型: 待处理 |

### 4. 添加相关链接

项目模板包含 6 个链接子区域：
- 上层归属 / 相关笔记 / 相关项目 / 相关OKR / 相关事件 / 相关人物 / 其他

链接来源：
- 相关领域 README（`04_领域/`）
- 相关 OKR（`02_日常/OKR/`）
- 1-3 个高置信度链接

### 5. 更新导航

更新目标目录 README 的 `## 导航入口`。

### 6. 报告

通知用户文件创建位置和内容概要。

## PRD 模板结构（`## 备注` section 内）

```markdown
### 问题陈述
要解决什么问题，为什么现在要做。

### 解决方案
高层方案描述。

### 用户故事
作为 X，我希望 Y，以便 Z。

### 实施决策
技术选型、架构方向等关键决定。

### 范围外
明确不做的内容。

### 补充说明
风险、依赖、时间线等。
```

## 规则

- 有明确目标的 PRD 始终使用项目模板.md
- 模糊想法使用收件箱模板.md
- 状态仅使用合法枚举值：进行中 / 已完成 / 废弃 / 暂停 / 搁置
- 创建文件后更新 `03_项目/进行中/README.md` 或 `01_收件箱/README.md` 导航
- 不自动创建 GitHub Issues（除非用户明确要求）
- 知识笔记添加 1-3 个高置信度的跨领域链接
