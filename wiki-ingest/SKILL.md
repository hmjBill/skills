# AI-Wiki 内容摄入

将外部内容（粘贴文本、文件、URL 描述）摄入 AI-Wiki 笔记库，按 PARA 结构路由到正确目录。

## 用途

本技能替代 wiki-ingest。不使用 `raw/→wiki` 管道，直接接收内容并按 PARA 规则路由。

## 步骤

1. **接收内容** — 接受用户提供的粘贴文本、文件或 URL 描述
2. **分析内容类型与主题** — 判断内容属于哪种类型
3. **确定目标目录** — 使用内容路由规则：
   - 无法分类 → `01_收件箱/`（`收件箱模板.md`，type: inbox）
   - 知识/参考资料 → `05_资源/`（`资源模板.md`，type: resource）
   - 书籍 → `06_媒体/读书/`（`读书模板.md`，type: book）
   - 媒体体验 → `06_媒体/`（`媒体模板.md`，type: media）
   - 人物 → `07_人物/`（`人物模板.md`，type: person）
   - 项目想法 → `03_项目/`（`项目模板.md`，type: project）
   - 领域责任 → `04_领域/`（`领域模板.md`，type: area）
   - 不确定时 → `01_收件箱/`，在内容中说明不确定性
4. **复制对应模板** — 从 `00_系统/模板/` 复制合适的模板
5. **填写 frontmatter** — 仅使用枚举注册表中的合法值
6. **填写内容区域** — 根据模板结构填充实际内容
7. **添加相关链接** — 按模板规则添加 `## 相关链接`：
   - 知识笔记：1-3 条高可信度链接
   - 执行笔记：链接到最近的 README/MOP
8. **更新目录导航** — 更新目标目录的 `README.md` `## 导航入口`
9. **报告创建结果** — 告知用户创建了什么

## 规则

- 必须使用 `00_系统/模板/` 中的模板
- 禁止凭记忆填写 frontmatter — 必须从模板复制
- frontmatter 修改使用 `patchField`/`patchFields`，禁止使用 `processFrontMatter`
- 仅使用合法枚举值：type、状态、收件类型、媒体类型、优先级等
- 批量摄入：处理多个条目时，按类型分组，让用户确认路由后再创建
- 禁止自动分类旧笔记

## 枚举值参考

所有 frontmatter 字段的合法值定义在 `.obsidian/types.json` 的枚举注册表中。创建笔记前必须确认所用值在注册表中存在。
