# AI-Wiki 网页内容摄入

从用户提供的 URL 提取干净正文内容，转化为 AI-Wiki 笔记。

## 触发场景

- "帮我保存这个网页"
- "把这个链接的内容收录"
- "从 URL 创建笔记"
- 直接提供一个或多个 URL

## 步骤

### 1. 接收 URL

用户提供一个或多个 URL。支持的来源类型：
- 文章/博客
- 文档页面
- GitHub README / Wiki
- 新闻页面
- 论文摘要页

### 2. 提取内容

使用 webfetch 工具获取 URL 内容：
- 提取标题、正文、作者、发布日期
- 过滤导航栏、广告、侧边栏、评论区等噪音
- 保留代码块、列表、表格等结构化内容
- 如果提取失败（付费墙、JS 渲染），告知用户并建议手动粘贴

### 3. 判断内容类型并路由

根据内容性质选择目标目录和模板：

| 内容类型 | 目标目录 | 模板 | type |
|---------|---------|------|------|
| 技术文章/教程 | `05_资源/` | 资源模板.md | resource |
| 书评/读后感 | `06_媒体/读书/` | 读书模板.md | book |
| 媒体评论/推荐 | `06_媒体/` | 媒体模板.md | media |
| 人物介绍/访谈 | `07_人物/` | 人物模板.md | person |
| 项目/工具介绍 | `03_项目/` 或 `05_资源/` | 项目/资源模板.md | project/resource |
| 不确定 | `01_收件箱/` | 收件箱模板.md | inbox |

### 4. 创建笔记

- 复制对应模板，填写 frontmatter（仅使用合法枚举值）
- 正文保留原始结构（标题、段落、列表、代码块）
- 在笔记末尾添加来源信息：

```
## 来源
- URL: [原始链接]
- 访问日期: YYYY-MM-DD
- 标题: [原标题]
```

### 5. 添加相关链接

按三层链接体系：
- 知识型笔记：1-3 个高置信度 wikilink
- 执行型条目：链接到 README/MOC

### 6. 更新导航

更新目标目录 README 的 `## 导航入口`。

### 7. 批量处理

多个 URL 时：
- 逐个提取内容
- 按类型分组展示路由方案
- 用户确认后批量创建
- 汇总报告

## 规则

- 必须使用 `00_系统/模板/` 中的模板
- 禁止凭记忆填写 frontmatter
- frontmatter 修改使用 `patchField`/`patchFields`
- 仅使用合法枚举值
- 提取失败时不要编造内容，告知用户
- 保留原文的实质性内容，但可以适当格式化
- 不自动删除原文中的任何实质性段落

## 枚举值参考

所有 frontmatter 字段的合法值定义在 `.obsidian/types.json` 的枚举注册表中。
