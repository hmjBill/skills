# 文案公式

25 个用于说服性幻灯片文案的公式。

## 核心公式

### PAS（问题-激化-方案）
**用途：** 问题页、痛点
**构成：** 问题 → 激化 → 方案
**模板：** “[痛点]？每[时间段]，[后果]。[方案] 可以解决。”

### AIDA（注意-兴趣-欲望-行动）
**用途：** CTA、收尾页
**构成：** 注意 → 兴趣 → 欲望 → 行动
**模板：** “[大胆陈述]。[利益细节]。[社会证明]。[CTA]。”

### FAB（特性-优势-利益）
**用途：** 功能页、产品展示
**构成：** 特性 → 优势 → 利益
**模板：** “[特性]让你[优势]，从而[利益]。”

### 不作为的代价
**用途：** 激化页、紧迫感
**构成：** 现状 → 损失 → 时间衰减
**模板：** “没有[方案]，你每[时间段]都在损失[金额]。”

### 之前-之后-桥梁
**用途：** 转变页、案例研究
**构成：** 之前 → 之后 → 桥梁
**模板：** “[之前的痛点]。[期望达成的状态]。[你的方案]就是桥梁。”

## 公式与幻灯片映射

| 幻灯片类型 | 主要公式 | 情绪 |
|------------|-----------------|---------|
| 标题/钩子 | AIDA、钩子 | 好奇 |
| 问题 | PAS、激化 | 挫败 |
| 成本/风险 | 不作为的代价 | 恐惧 |
| 方案 | FAB、BAB | 希望 |
| 功能 | FAB | 信心 |
| 进展 | 证据堆叠 | 信任 |
| 社会证明 | 证言 | 信任 |
| 定价 | 价值堆叠 | 信心 |
| CTA | AIDA、紧迫感 | 紧迫 |

## 标题模式

### 力量词
- “停止[坏事]”
- “在[时间范围]内获得[期望结果]”
- “[形容词]的[行动]方式”
- “为什么[受众]选择[产品]”
- “[数字] 种[达成目标]的方法”

### 对比模式
- “[旧方式]已死。迎接[新方式]。”
- “不要[坏行为]。而要[好行为]。”
- “从[痛点]到[收益]。”

### 社会证明模式
- “[数字]+ [用户/公司]信任[产品]”
- “加入[知名公司]和[知名公司]”
- “曾在[出版物]亮相”

## 快速参考

| 需求 | 使用公式 |
|------|------------|
| 制造紧迫感 | 不作为的代价、稀缺性 |
| 建立信任 | 社会证明、证言 |
| 展示价值 | FAB、价值堆叠 |
| 促成行动 | AIDA、CTA |
| 讲述故事 | BAB、故事弧 |
| 呈现数据 | 证据堆叠 |
