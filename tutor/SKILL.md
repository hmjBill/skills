# AI-Wiki 交互式测验

基于 AI-Wiki 中已有的学习笔记进行交互式测验和知识巩固。

## 定位

基于 tutor skill 适配 AI-Wiki 结构。核心变化：不依赖 StudyVault/，使用 `05_资源/`、`04_领域/`、`06_媒体/读书/` 中任意笔记作为学习材料。

## 工作流

### 1. 确定学习范围

- 用户指定主题或目录（如 `05_资源/编程`）
- 或用户提供特定笔记路径
- 未指定时扫描 `05_资源/` 中适合测验的内容

### 2. 加载学习材料

- 读取目标笔记
- 提取关键概念、事实、流程、关系

### 3. 评估现有掌握度（可选）

- 询问用户对主题的熟悉程度
- 或从简短诊断测验开始

### 4. 交互式测验

按以下题型展开：

- **概念回忆**：「请解释 X 概念」→ 对比笔记内容评分
- **填空/选择**：基于笔记中的关键信息出题
- **场景应用**：「在 Y 场景下如何运用 X」
- **对比分析**：「比较 A 和 B 的异同」
- **代码/操作题**：技术内容给出实际操作题

### 5. 反馈与巩固

- 即时反馈：正确 / 部分正确 / 需要复习
- 引用原始笔记位置：「参见 [[05_资源/xxx]] 的相关章节」
- 答错时提供原文摘录

### 6. 薄弱项追踪

- 记录本次会话中表现薄弱的概念
- 建议用户在相关笔记中添加复习标记
- 不自动修改笔记（除非用户要求）

### 7. 会话总结

- 覆盖的概念列表
- 掌握度评估
- 建议下一步学习方向

## 出题规则

- 所有题目必须基于笔记库中的实际内容，不凭空编造
- 每次会话覆盖 3-8 个概念
- 难度递进：回忆 → 理解 → 应用
- 错误答案选项具有合理迷惑性（基于常见误解）

## 规则

- 对 vault 内容默认只读（用户要求添加复习标注时除外）
- 所有测验内容来源于实际 vault 笔记
- 反馈中使用 `[[wikilink]]` 引用来源笔记
- 不依赖任何 `StudyVault/` 结构
- 可使用 AI-Wiki 中任意包含学习内容的目录
