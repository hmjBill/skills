# AI-Wiki 全库问答

基于 AI-Wiki 笔记库的实际内容回答问题，所有回答附带 `[[wikilink]]` 引用。

## 用途

本技能替代 wiki-query。不依赖 index.md，而是使用 AI-Wiki 的全库搜索能力查找相关内容。

## 步骤

1. **理解用户问题** — 明确查询意图和范围
2. **全库搜索** — 使用 Obsidian search（`obsidian search query="..."`）或 `grep`/`ripgrep` 在所有目录中搜索相关笔记
3. **精读相关笔记** — 完整阅读 2-6 篇最相关的笔记
4. **沿 wikilink 扩展** — 跟随笔记中的 wikilink 获取更多上下文（1-2 跳）
5. **合成回答** — 整合笔记库内容生成回答，使用 `[[完整路径|显示名]]` 格式引用实际笔记
6. **可选保存** — 若用户需要保存回答，使用 `00_系统/模板/收件箱模板.md` 创建笔记到 `01_收件箱/`，并更新 `01_收件箱/README.md` 导航

## 规则

- 只引用笔记库中的实际内容，不引用通用知识
- 使用 `[[完整路径|显示名]]` 格式的 wikilink
- 诚实标注不确定性 — "在笔记库中未找到关于 X 的内容"
- 禁止创建 wiki 页面或更新 index.md
- 保存结果时使用 `00_系统/模板/收件箱模板.md`，更新 `01_收件箱/README.md` 导航

## 引用格式

```
根据 [[05_资源/编程/Python笔记|Python笔记]] 中的记录...
详见 [[03_项目/个人网站/README|个人网站项目]] 的规划...
```

## 参考

- AI-Wiki 目录结构：`01_收件箱`（收件箱）、`02_日常`（日常）、`03_项目`（项目）、`04_领域`（领域）、`05_资源`（资源）、`06_媒体`（媒体/读书/观影）、`07_人物`（人物）、`08_归档`（归档）
