# 分诊标签

技能使用五个规范分诊角色。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库跟踪器中的标签 | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估此 issue |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完全指定，可由 AFK agent 处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会被处理 |

当技能提到某个角色（例如"应用 AFK-ready 分诊标签"）时，使用此表中对应的标签字符串。

编辑右列以匹配你实际使用的词汇。
