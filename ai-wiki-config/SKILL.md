# AI-Wiki 配置检查

检查和展示 AI-Wiki 个人知识库的现有系统配置与架构状态，只读操作。

## 用途

本技能替代 wiki-config。AI-Wiki 拥有自己的配置体系（架构说明.md、Agent操作指南.md、types.json、模板/），本技能不部署脚手架，仅做只读验证和状态展示。

## 步骤

1. **定位笔记库根目录** — 查找 `.obsidian/` 目录或 `00_系统/` 目录
2. **验证核心文件** — 检查以下文件是否存在：
   - `00_系统/架构说明.md`
   - `00_系统/Agent操作指南.md`
   - `.obsidian/types.json`
3. **验证模板目录** — 检查 `00_系统/模板/` 下所有模板文件是否完整（预期：19 个模板文件）
4. **验证目录结构** — 检查 `00` 至 `09` 所有目录是否存在且包含 `README.md`
5. **输出状态报告** — 列出已存在、缺失、异常的项目
6. **初始化请求** — 若用户要求"初始化"，说明 AI-Wiki 不需要额外初始化，它使用自身的系统

## 规则

- 禁止创建 `wiki-config.md`、`wiki-schema.md` 或 `templates/` 脚手架
- 禁止创建 `raw/`、`ingested/` 目录
- 默认只读操作，除非用户明确要求修复特定问题
- 架构信息参考 `00_系统/架构说明.md`
- 操作规则参考 `00_系统/Agent操作指南.md`

## 参考

- AI-Wiki 使用 PARA 变体：`00_系统` 至 `09_受控信息`，中文目录名加数字前缀
- 模板存放于 `00_系统/模板/`，包含 19 个中文模板
- 枚举注册表定义在 `.obsidian/types.json`，包含 140 个字段
- frontmatter 系统字段用英文（type/tags/date/completed），业务字段用中文（状态/收件类型/来源/等级）
