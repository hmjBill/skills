# AI-Wiki 链接整合

为 AI-Wiki 笔记建立语义链接并更新目录导航，遵循三层链接体系。

## 用途

本技能替代 wiki-integrate。针对 AI-Wiki 的三层链接体系（README 导航 → 高可信度 wikilink → DataviewJS）进行链接整合。

## 步骤

1. **读取目标笔记** — 获取笔记全文，理解内容
2. **判断笔记类型**：
   - **知识型**（`04_领域`、`05_资源`、`06_媒体`、`07_人物`、`03_项目` 非待办池）：检查跨领域语义链接
   - **执行型**（`01_收件箱` 条目、`02_日常`、`03_项目/待办池`）：链接到最近的 README/MOP
3. **知识笔记链接**：
   - 读取该笔记所基于的模板，确认 `## 相关链接` 区的 HTML 注释指引
   - 搜索相关笔记（2-8 个候选）使用 search/grep
   - 阅读候选笔记，仅选择 1-3 条高可信度链接
   - 每条链接必须能用一句话解释关联原因
   - 追加到 `## 相关链接` 的扁平列表中（不要创建子节，你的模板不使用子节分组）
4. **验证/更新目录 README** — 确保目标目录的 `## 导航入口` 包含该笔记
5. **禁止重写内容** — 只添加 wikilink 和更新导航

## 链接评判标准

只添加具有明确语义关系的链接：
- 上游/下游依赖关系
- 项目应用关系
- 共享核心概念
- 直接影响关系

禁止添加以下类型的链接：
- 仅为同分类
- 仅名称相似
- 仅时间接近
- "可能有关"
- 为了图谱连通性

## 规则

- 知识笔记最多 1-3 条跨领域链接
- 执行笔记只链接到 README/MOP
- 禁止使用 frontmatter `related` 字段
- 禁止修改笔记正文内容 — 只修改 `## 相关链接` 区域和 README 导航
- frontmatter 修改使用 `patchField`/`patchFields`，禁止使用 `processFrontMatter`

## 各模板的链接规则

wiki-integrate 执行时必须先读取目标笔记对应的模板，按模板注释指引添加链接：

| 模板类型 | 默认链接 | 可补语义链接 |
|---------|---------|------------|
| 领域/资源/媒体/读书/人物/项目 | 无固定默认 | 有则补 1-3 个，无则不补 |
| 待办池 | `[[03_项目/待办池/README]]` | 不补 |
| 收件箱 | `[[01_收件箱/README]]` + 1 个出链到对应目录 | 可补 1 个 |
| 事件/跨天事件/循环事件 | `[[02_日常/事件/README]]` | 关联日记/项目/人物 |
| 每日记录 | `[[02_日常/日记与复盘/每日/README]]` | 关联事件/OKR |
| 周复盘 | `[[02_日常/日记与复盘/周复盘/README]]` | 关联具体日期日记 + OKR |
| 月复盘 | `[[02_日常/日记与复盘/月复盘/README]]` | 关联具体日期日记 + OKR |
| 季度复盘 | `[[02_日常/日记与复盘/季度复盘/README]]` | 关联具体日期日记 + OKR |
| OKR | `[[02_日常/OKR/README]]` | 关联上级 OKR |
