# AI-Wiki 链接整合

为 AI-Wiki 笔记建立语义链接并更新目录导航，遵循三层链接体系。

## 用途

本技能替代 wiki-integrate。针对 AI-Wiki 的三层链接体系（README 导航 → 高可信度 wikilink → DataviewJS）进行链接整合。

## 步骤

1. **读取目标笔记** — 获取笔记全文，理解内容
2. **判断笔记类型**：
   - **知识型**（`04_领域`、`05_资源`、`06_媒体`、`07_人物`、`03_项目` 非待办池）：检查跨领域语义链接
   - **执行型**（`01_收件箱` 条目、`02_日常`、`03_项目/待办池`）：链接到最近的 README/MOP
3. **知识笔记链接**：
   - 搜索相关笔记（2-8 个候选）使用 search/grep
   - 阅读候选笔记，仅选择 1-3 条高可信度链接
   - 每条链接必须能用一句话解释关联原因
   - 添加到 `## 相关链接` 的对应子节（上层归属/相关笔记/相关项目等）
4. **验证/更新目录 README** — 确保目标目录的 `## 导航入口` 包含该笔记
5. **禁止重写内容** — 只添加 wikilink 和更新导航

## 链接评判标准

只添加具有明确语义关系的链接：
- 上游/下游依赖关系
- 项目应用关系
- 共享核心概念
- 直接影响关系

禁止添加以下类型的链接：
- 仅为同分类
- 仅名称相似
- 仅时间接近
- "可能有关"
- 为了图谱连通性

## 规则

- 知识笔记最多 1-3 条跨领域链接
- 执行笔记只链接到 README/MOP
- 禁止使用 frontmatter `related` 字段
- 禁止修改笔记正文内容 — 只修改 `## 相关链接` 区域和 README 导航
- frontmatter 修改使用 `patchField`/`patchFields`，禁止使用 `processFrontMatter`

## 参考

- 三层链接体系：README 导航 → 高可信度 wikilink（知识笔记 1-3 条）→ DataviewJS
- 知识型目录：`04_领域`、`05_资源`、`06_媒体`、`07_人物`
- 执行型目录：`01_收件箱`、`02_日常`、`03_项目/待办池`
