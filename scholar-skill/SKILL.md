# 学术论文深度阅读与知识内化

学术论文深度阅读和知识内化，输出到 AI-Wiki 结构。基于 scholar-skill 改编，适配 AI-Wiki 的 PARA 目录体系和模板系统。

## 核心适配

本 skill 不使用 scholar-skill 原有的 `1-Papers/2-Knowledge/3-MOCs/` 结构，而是路由到 AI-Wiki 对应目录：

- 论文笔记 → `06_媒体/读书/`（使用 `读书模板.md`）
- 知识提取 → `05_资源/` 子主题（使用 `资源模板.md`）
- MOC → 利用 `04_领域/` 或 `05_资源/` 现有 README 结构
- 无需 `python configure.py`

## 工作流

### 1. 接收论文

用户提供论文标题、PDF 路径或粘贴内容。

### 2. 分级阅读选择

询问用户阅读深度：

- **L1 快速扫描**：摘要 + 结论 + 关键图表 → 读书模板写入 `06_媒体/读书/`
- **L2 重点阅读**：+ 方法 + 结果 + 讨论 → 读书模板，附带详细笔记
- **L3 深度阅读**：+ 相关工作 + 附录 + 完整分析 → 读书模板 + 单独资源笔记

### 3. 信息提取

- 核心贡献、方法论、关键发现、局限性
- 与用户现有知识的关联
- 可操作的见解

### 4. 笔记创建

- 主笔记用 `00_系统/模板/读书模板.md`，放入 `06_媒体/读书/`
- L3 有衍生知识点时，额外在 `05_资源/` 下用 `资源模板.md` 创建子笔记
- 填写 frontmatter：`type: book`、`作者`、`评分`、`tags`
- 摘录章节放入 `## 摘录`
- 核心发现放入 `## 阅读笔记`
- 评价放入 `## 书评`

### 5. 知识关联

- 检查 `05_资源/` 和 `04_领域/` 中是否有相关笔记
- 添加 1–3 个高置信 wikilink 到 `## 相关链接`
- 链接必须能用一句话说明关系

### 6. 更新导航

更新 `06_媒体/读书/README.md` 的 `## 导航入口`。

## 阅读协议

从 scholar-skill 的四阶段阅读法改编：

1. **扫描阶段**：标题、摘要、关键词、引言标题、结论
2. **定位阶段**：识别核心论点、方法论、关键证据
3. **深入阶段**：详细阅读，记录关联，评估论点
4. **内化阶段**：与现有知识综合，识别知识缺口

## 知识提取（L3 可选）

- 提取可复用的概念、方法、模式
- 每个知识点写入单独的 `05_资源/` 笔记（资源模板）
- 在读书笔记中添加链接

## 关键规则

- 始终使用 `00_系统/模板/` 模板
- 论文路由到 `06_媒体/读书/`（`读书模板.md`，`type: book`）
- 知识笔记路由到 `05_资源/`（`资源模板.md`，`type: resource`）
- 创建文件后更新 README 导航
- 仅使用合法枚举值
- 不创建 `1-Papers/` 或类似顶层目录
- 链接：知识笔记添加 1–3 个高置信跨领域链接
