# AI-Wiki 学习材料导入

将学习材料（文档、网页、代码库）导入 AI-Wiki，生成结构化学习内容和测验素材。

## 定位

基于 tutor-setup skill 适配 AI-Wiki 的 PARA 结构。核心变化：不创建 StudyVault/ 顶层目录，所有内容路由到现有 AI-Wiki 目录。

## 工作流

### 1. 接收材料

用户提供内容来源：
- 文本或文档内容
- 网页描述
- 代码片段或代码库
- 其他学习材料

### 2. 分析内容类型并路由

根据内容性质决定去向：

| 内容类型 | 目标目录 | 模板 | frontmatter type |
|---------|---------|------|-----------------|
| 文档/知识 | `05_资源/` | 资源模板.md | `resource` |
| 代码/技术 | `05_资源/` 对应技术子目录 | 资源模板.md | `resource` |
| 有明确目标的学习计划 | `03_项目/` | 项目模板.md | `project` |
| 长期责任领域知识 | `04_领域/` | 领域模板.md | `area` |
| 不确定 | `01_收件箱/` | 收件箱模板.md | - |

### 3. 分解学习单元

- 将内容按主题分解为独立笔记
- 每个笔记基于对应模板创建
- 建立笔记间的学习路径链接（通过 `## 相关链接`）

### 4. 创建学习体系

- 主笔记作为学习概览，放到 `05_资源/` 下
- 子主题笔记按需创建
- 每个笔记包含 `## 相关链接` 连接前后学习单元

### 5. 生成测验素材（可选）

- 从内容中提取关键概念
- 生成问答对存入笔记的专用 section
- 标注难度等级：基础 / 中级 / 高级

### 6. 更新导航

更新目标目录 README 的 `## 导航入口`。

## 输入模式

### 文档模式

输入文本/文档内容 → 按章节拆分 → 每章节一个资源笔记 → 串成学习路径

### 代码库模式

分析代码结构 → 按模块/功能拆分 → 每个模块一个资源笔记 → 标注代码路径

## 规则

- 始终使用 `00_系统/模板/` 下的模板
- 路由到现有 PARA 目录，绝不创建新的顶层目录
- 不创建 `StudyVault/` 或任何新的顶层结构
- 所有笔记默认使用资源模板.md（type: resource）
- 创建文件后更新对应 README 导航
- 知识笔记添加 1-3 个高置信度的跨领域链接
